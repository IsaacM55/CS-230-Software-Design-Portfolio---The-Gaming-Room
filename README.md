# CS-230-Software-Design-Portfolio---The-Gaming-Room

The Gaming Room was the client for this project, and they wanted to expand their existing Android game, Draw It or Lose It, into a web-based application that could run across multiple platforms. The software needed to support multiple teams and players, manage game sessions, and ensure that each game, team, and player had a unique identifier. One aspect I believe I handled particularly well was identifying the software requirements and explaining how different  operating systems could support the application. I was able to compare Windows, Linux, and macOS while considering factors such as security, performance, scalability, and overall compatibility.

Working through the software design document helped me better understand how important planning is before beginning the development process. By identifying the requirements and evaluating different platforms, I was able to determine which technologies would best support the clients needs. This process helped me organize my thoughts and consider potential challenges before writing code. If I could revise one part of my documentation, I would improve the level of detail in my system architecture explanations and include additional diagrams to better demonstrate how the components interact. I believe these improvements would make the document easier for other developers to understand and follow.

When designing the software, I focused on understand the client's requirements and how users would interact with the application. Considering the needs of the users was important because the application needed to provide a consistent and reliable experience across different devices and operating systems. I approached the design by breaking down the requirements, comparing available technologies, and evaluating their advantages and limitations. In future projects, I would continue using this approach while incorporating more detailed planning, diagrams, and testing strategies. This experience helped me understand dhow proper software design can improve the development process and contribute to creating applications that are secure, efficient, and maintainable.
